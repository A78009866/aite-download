# Aite — صفحة التحميل

صفحة ثابتة (HTML + صور + خطوط) لتحميل تطبيق Aite لأندرويد.

- `index.html` — الصفحة
- `assets/` — الشعارات وخطوط Alexandria

## النشر على Vercel
استورد المستودع في Vercel: Framework Preset = **Other**، بدون أمر بناء، ومجلد الإخراج هو الجذر (`./`).

لتحديث رابط ملف APK عدّل `href` في زر التحميل داخل `index.html`.
